# ContaGest Unified Enterprise UI Kit

Kit visual unificado para que todas las pantallas mantengan acabado ERP profesional.

## Componentes
- `Button`: acciones principales, secundarias y de riesgo.
- `PageHeader`: encabezado estándar de módulo con eyebrow, título, descripción y acciones.
- `MetricGrid` / `MetricCard`: KPIs financieros, fiscales e inventario.
- `Section`: contenedor de panel enterprise para widgets, formularios y reportes.
- `DataTable`: tabla con cabecera sticky, números monoespaciados y alineación financiera.
- `Toolbar`: búsqueda y acciones de módulo.
- `Timeline`: actividad reciente y auditoría.

## Uso recomendado
Las páginas nuevas deben importarse desde `src/components/ui/index.js` y evitar clases sueltas. El CSS vive en `src/styles/precision-ledger.css` bajo el bloque `v10.3 Enterprise UI Kit`.
