# Style Guide — Hípico Control

## Personalidad
Operativa, rápida, sobria y confiable. Debe sentirse como una herramienta de trabajo, no como una demo ni como una casa de apuestas promocional.

## Jerarquía
- Estado de carrera y excepciones tienen prioridad visual.
- Números monetarios usan tabular numerals y alineación consistente.
- Rojo solo para bloqueo/pérdida/error; verde para confirmación; ámbar para revisión.
- El color del grupo identifica contexto, nunca sustituye texto.

## Lenguaje
Usar: `Sin conexión`, `Sincronizando`, `Revisar`, `Confirmada`, `Fuera de tiempo`, `Cerrada`.
No usar en la interfaz normal: `QA`, `TEST`, `demo`, `versión local`, `modo local` o nombres de canales internos de release.

## Mobile
Acciones primarias accesibles con una mano; tabla se transforma en tarjetas; teclado no tapa confirmaciones; barra inferior estable.
