# MCP integration contract

GitHub: existing authenticated connector/CLI, repository-scoped; read before write. Supabase: only authorized nonproduction project, read schema before any migration; no credentials in Git. Vercel: read deployment and exact SHA before approved deploy. Figma: authorized designs only. Playwright/SDK/Gradle/.NET CLI use actual local tools; do not label CLI as MCP. OpenAI documentation MCP: `codex mcp add openaiDeveloperDocs --url https://developers.openai.com/mcp` (official documentation). Verify `codex mcp list` and read-only smoke before enabling; other endpoints must be obtained from their official documentation. Do not overwrite existing config or enable broad permissions. Status: configuration guidance committed; runtime connection not tested.
