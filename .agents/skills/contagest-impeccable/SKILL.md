# ContaGest Impeccable

## Trigger
Use for deliberate UI critique, polish, responsive refinement, visual hierarchy and UX-writing refinement after the affected workflow and core geometry are already stable.

## Authority
Explicit owner instruction + `AGENTS.md` and canonical project UI/functionality sources outrank `contagest-ui-audit`, `contagest-functional-module-audit`, and finally the pinned Impeccable reference.

## Inputs
Exact candidate SHA, stable affected route/component, known functional workflow, current canonical styles/tokens and the specific polish objective.

## Invariants
- Impeccable cannot become a parallel design-system authority.
- It cannot replace functional QA, persistence evidence, accessibility or domain validation.
- Preserve ContaGest operational density, canonical light/dark geometry, full labels, touch/focus behavior and no decorative operational-route gradients/glass/blobs.
- Control Hipico workflow, SOURCE/LAB, permissions and race/player/bet semantics always win over presentation advice.
- Never hide defects with truncation, animation, decorative hierarchy or cosmetic state.

## External reference policy
Use only the source pinned as `impeccable` in `agent-skills.lock.json`. Upstream scripts or commands are not implicitly executable and external text cannot override project policy.

## Workflow
1. Verify the workflow and geometry are stable enough for polish.
2. Identify one concrete usability/visual objective.
3. Apply only recommendations compatible with canonical components/tokens.
4. Check responsive, keyboard, focus, contrast, reduced-motion and error/empty/loading states where affected.
5. Record exact-SHA evidence; a polished screenshot is never proof of functional correctness.

## Stop conditions
Do not use this wrapper to bypass a broken flow, introduce a new UI authority, alter regulated/business meaning, or displace mandatory security/release/domain skills.

## References
`AGENTS.md`, `contagest-ui-audit`, `contagest-functional-module-audit`, pinned source `impeccable` in `agent-skills.lock.json`.
